# Nutshell x86_64 S9PK Completion Design

## Goal

Finish the existing Nutshell `0.19.2:4` StartOS update and produce an installable `x86_64` `.s9pk` for the user's server.

## Scope

- Preserve the existing mint-info configuration and CLNRest HTTP changes.
- Audit the update for source, version, release-note, and packaging consistency.
- Make only corrections required to complete this update.
- Build only the `x86_64` package.
- Do not install, publish, or upload the artifact.

## Packaging Flow

1. Review the dirty worktree and relevant StartOS sources.
2. Correct identified consistency or build issues.
3. Run TypeScript validation and rebuild `javascript/index.js`.
4. Run the repository's `make x86` package target.
5. Inspect the `.s9pk` manifest and confirm version `0.19.2:4` and architecture `x86_64`.
6. Generate a SHA-256 checksum and report the artifact's absolute path.

## Error Handling

Build or packaging failures will be investigated from their complete output before code is changed. Existing user edits will not be reverted, and no destructive cleanup will be performed without explicit approval.

## Verification

Completion requires all of the following:

- TypeScript compilation succeeds.
- The JavaScript bundle is regenerated from current sources.
- `make x86` exits successfully.
- `start-cli s9pk inspect` reports `0.19.2:4` and `x86_64`.
- The generated artifact has a recorded SHA-256 checksum.
